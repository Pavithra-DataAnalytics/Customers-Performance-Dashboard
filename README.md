📊 Customer Performance Dashboard

📌 Overview

This Power BI dashboard provides insights into customer demographics, revenue segmentation, and purchasing behavior.

🔍 Key Insights

- Customer age distribution
- Revenue by age group
- Customers with vs without children
- Top-performing buyers
- Gender-based earnings analysis

🛠 Tools Used

- Power BI
- Data Modeling
- DAX


📁 Files Included

- ".pbix" file (Power BI report)

🚀 How to Use

1. Download the ".pbix" file
2. Open in Power BI Desktop
3. Explore visuals and insights
